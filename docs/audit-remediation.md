# 2026-10-10 对抗审查修复说明

本次修复覆盖流程规则、示例适配代码及交付检查。模型运行数据保留为修复前的历史记录，修复后的验收范围见本页末尾。

## 已修复

- 候选索引：`top_response_table` 按排名后的药物 ID 提取响应，保留对应浓度，不再取输入顺序前几项。
- 质量判定：NaN/Inf 逐条件失败；响应幅度、方向和评分区分度分开记录。相同疾病评分不再导致有效预测失败，高余弦不再被直接解释为相同响应。
- 数据保存：三个药筛适配器和 LINCS 示例保存完整预测、基线、响应、基因顺序和条件 ID。新运行使用唯一目录，不覆盖旧结果。
- CellOracle 对照：改称随机化表达变化的投影对照，撤回“相减后得到扰动特异信号”的解释；代码字段改为 `vector_difference_*`。保存基线表达及拟合网络，Top 基因图显示有符号均值。
- 输入与路由：区分 PRnet 模型接口、LINCS 适配器和外部基线适配器。剂量、时间按后端确定；固定 A549 对照不标成用户样本。
- 缺测：评分从实际映射表读取疾病方向，使用共同有效基因掩码。模型必需基因缺失时，当前示例停止该路推理，不做未经验证的补零。疾病参考构造中的负值哨兵改按缺失处理；历史差异表未因此自动重算。
- 零模型：删除“只换药物名称即可构造零分布”及“退化检查可替代零模型”的要求。描述性评分允许无零模型，显著性推断需说明检验对象、可交换性和校正。
- 分发：`scripts/package_skill.py` 从源文件构建 ZIP，排除数据、权重、运行目录，内置逐文件 SHA256 并与磁盘核对。

## 药筛评分的执行方式

示例保留模型预测；逆转评分是可选下游步骤。Agent 核对实际基因空间、效应尺度与比较目的后，可自行在 `examples/lung_cancer/drug_screen/data/` 记录 `<后端名>_scoring_contract.json`，无需新增用户审批。后端名为 `PRnet`、`chemCPA` 或 `UniPert-G2CP`。

此记录需包括：`metric`（当前适配器为 `negative_cosine`）、`response_scale`、`disease_scale`、`scale_justification`、`comparison_scope`、`minimum_common_genes` 及 `disease_source_sha256_16`。最后一个字段绑定实际 `GSE81089_landmark978_signature.csv`；最低覆盖数按问题说明依据，不能照搬一个通用阈值。

这份记录保存尺度选择与科学判断依据，尺度适用性需结合数据核对。若跨平台效应无法合理转换，不创建该记录，交付原生预测；记录缺失、源文件变更或共同基因不足时，代码跳过评分并写明原因。使用其他评分方法时，方法名、实现与检验需同步更新。

## 历史产物处理

- UniPert 的 `top20_drug_per_gene_predicted_response.csv` 实际保存输入顺序前 20 项，与历史排名前 20 的重合数为 0。该文件不能作为候选 Top 20 的热图源表。历史运行目录中已改名为 `input_first20_drug_per_gene_predicted_response.csv`，内容 SHA256 保持不变，缺失候选响应标为不可恢复。
- 三个 FDA 药筛运行的 `raw/` 均为空，仅有局部响应表，无法据此恢复全库响应或重新计算全部质量指标。旧状态按原规则保留作追溯，新规则验收另行记录。
- CellOracle 旧 `specific_shift_*` 字段仅是原始投影与随机化投影的向量差长度，不支持特异性结论。原始数值保留，解释已在报告中更正。
- 原始 `reproduce/` 目录属于历史运行快照，当前维护入口是仓库中的 `examples/`。修正后的缺测策略可能改变疾病差异及评分，重跑时应生成新运行目录并标明版本。
