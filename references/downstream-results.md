# 下游结果与图表契约

## 选择与交付原则

先根据后端真实输出选择图组，再根据研究问题补充分析。下文的“默认”表示条件满足时主动生成；缺少输入、有效候选或参考资源时，记录原因并跳过，不凑图数。用户指定只画某张图时按其范围执行。

| 实际结果 | 默认展示 | 有条件扩展 |
| --- | --- | --- |
| KO/OE 逐基因表达或模拟差值 | 有方向的 Top 基因图、响应热图；可映射且满足基因集分析条件时加通路富集 | 网络图、状态变化、KO/OE 配对比较、真实扰动验证 |
| 仅网络/模块影响 | 受影响基因或模块评分图、网络图 | 有适用排序或基因集合时做功能富集；无方向的网络分数不解释为激活/抑制 |
| 仅细胞/基因 embedding | 状态距离/影响评分分布、候选扰动排名 | 有定义好的目标状态时比较接近程度；有可靠投影规则时展示状态位置 |
| 药物逐基因响应与有效评分 | 候选排名、评分分布、候选药物响应热图、退化检查图 | 疾病逆转、评分矩阵、剂量曲线、真实响应验证 |
| 仅药物原生排名 | 排名图、可用分数分布及覆盖情况 | 有可比背景或剂量时绘制评分热图；不补逐药基因响应 |

每张图回答一个明确问题。预测结果、技术质量检查、真实数据验证分开组织。示例脚本已有的图片是基础产物；执行本规则时按保存的数值表补齐适用图，不将本图谱目录写成所有分支均已实测。

## KO

### 逐基因表达后端

- 表：目标基因、细胞类型、基线、扰动表达、效应值、单位、条件、来源
- 图：优先带正负方向的 Top 基因图及响应热图；火山图仅在有合适效应量和统计检验时生成，不能为单份模拟差值补造 p 值
- 富集：按下文共用规则运行 GO/KEGG/Reactome 的适用分析，记录背景基因、基因集版本和多重检验

### KO 默认图组与扩展

| 图形 | 输入与画法 | 需要说明的口径 |
| --- | --- | --- |
| `gene_effects`：基因响应条形图/点图 | 以平均绝对变化或预先确定的效应量选择 Top 基因；纵轴基因，横轴有符号的平均变化，用两种颜色区分正负 | 列出选基因和展示分数的不同口径；可另画绝对变化图，但不能将绝对值解释为上调 |
| `response_heatmap`：响应热图 | 行为受影响基因，列为匹配条件、细胞类型或样本，颜色为有符号的模拟/预测变化；单条件可显示基线与干预后的表达 | 差值图用以零为中心的对称色标；基线/干预表达使用相同尺度。标记缺测，不以零代替 |
| `pathway_enrichment`：功能富集图 | 使用合格的全基因排序做 GSEA，或对按明确规则选出的基因做 ORA；绘制气泡图/条形图及重点基因集的 GSEA 曲线 | 写清 NES、富集比例和 FDR 分别由什么编码。仅按 Top 数量选基因时称“高影响基因”，不称“显著差异基因” |
| `state_shift`：状态位移图 | 有状态位移时默认生成。用同一坐标展示细胞群背景、扰动箭头和随机化对照；按细胞类型着色，只有组织标签时明确标“组织来源” | 图内写目标基因、干预、嵌入方法和箭头缩放；单纯二维位置或箭头不等于真实分化轨迹 |
| `shift_distribution`：位移分布图 | 有状态位移时默认按群比较扰动与随机化对照的位移幅度，使用箱线/小提琴图；有供体时可叠加供体汇总点 | 细胞分布是描述统计；供体才是相应生物学重复。未做正式检验不画显著性星号 |
| `network_effects`：调控网络图 | 有实际调控边/模块时生成目标基因邻域或高影响模块；节点颜色编码明确的基因效应，边宽编码权重 | 只有基线网络就标“基线调控网络”；只有匹配前后网络才能画边权变化。不要把先验连接画成新发现的调控关系 |
| `perturbation_scores`：轨迹/扰动评分图 | 有可信轨迹、分化方向或目标状态时，可展示沿轨迹评分或不同候选的评分排名 | 保存评分定义和参考方向。没有轨迹参照时跳过分化促进/抑制评分 |

### 网络/状态后端

- 表：调控边、网络权重、模块、状态位移、embedding 距离
- 图：网络图、模块图、向量场、状态位移图
- 对照：CellOracle 本流程用其随机化对照位移作技术比较，记录具体随机化方法，不将空扰动当成未扰动向量场。原始位移与对照用同一坐标和缩放；若显示两者之差，另图注明“向量差”及计算顺序，不称已验证的扰动特异信号
- 不生成：逐基因 log2FC、实测细胞比例、因果结论

CellOracle 同时提供模拟 `delta_X` 与状态位移时，可组合逐基因和状态图组；`delta_X` 的单位为模型表达尺度，不自动转成 log2FC。只有网络或 embedding 时，不反推不存在的逐基因表达。

## OE

- 保存目标基线、设定值、实际模拟值、表达尺度和范围检查
- 逐基因后端：保存全量效应表和通路表
- embedding 后端：保存状态距离、方向和排序
- KO/OE 都成功时：输出并排结果和差值，不预设方向相反
- 没有真实 OE 数据：标记 `unvalidated`，不阻断虚拟结果

### OE 默认图组与扩展

有逐基因结果时生成 KO 中的基因响应、响应热图和适用的通路富集；有状态位移时配套状态位移及对照分布。所有标题明确标为 OE，结果独立计算。

- `oe_setting`：目标表达设定图。对有数值表达设定的后端，画目标基因基线表达分布，并标出设定值；有输出值时单独展示实际模拟值。标明尺度，不能把模型数值标成实验过表达倍数。只有条件编码时记录编码，无须补画表达分布。
- `target_state_shift`：目标状态接近程度图。只有用户提供或已有明确参照状态时，计算扰动前后到参照的距离/相似性变化，画按群分布或候选基因排名。写明距离定义、目标状态来源和正负方向；不把“更接近”直接写成治疗或分化成功。
- `ko_oe_comparison`：同一目标的 KO/OE 并排图。有匹配基线、基因空间和尺度时，画共享色标的响应热图或同基因效应点图，显示同向、反向和无明显变化；不预设两种扰动镜像对称。
- `combination_effects`：单基因与组合干预图。只有后端支持且已有对应预测时展示；如计算偏离加性效应，保存同尺度的单基因、组合预测和加性参照，不默认标为实验协同。

Geneformer 等只输出 embedding 的路线：默认画影响/距离分布和候选排名；有目标状态时加接近程度图。不要要求其生成表达变化热图、表达 log2FC 或表达 GSEA。若分析基因 embedding 影响的功能富集，标为“基因表征影响富集”，并说明排序量不含表达方向。

## 药筛

- 表：drug_id、结构/embedding 来源、剂量、时间、细胞、分数、名次、覆盖状态
- 逐基因后端：另存每药完整基因效应表
- 排名后端：只存排名；不生成逐药 DEG
- 图：按下文默认图组及条件扩展生成排名、响应、评分和质量检查图
- 疾病参照：只有疾病表达和药物响应量纲可比时计算对应数值
- 常用打分：预测响应向量与疾病方向向量的余弦相似度，逆转分数取负余弦；默认报告实际覆盖的全基因空间，有可靠差异基因集合时再报告该子空间。标明集合来源、覆盖率、缺测处理和分数方向
- 一致性检查：LINCS 这类有留出实测的条件，可以报告"预测响应 vs 实测响应"的逐条件相关系数。这是内部一致性，不等于实验验证

### 药筛默认图组与扩展

| 图形 | 输入与画法 | 生成条件与解释 |
| --- | --- | --- |
| `drug_ranking`：候选排名图 | 纵轴药物、横轴有效评分；保留正负值，标出细胞背景、剂量/剂量汇总方式 | 有后端原生分数或已定义评分时生成；无疾病参照不计算疾病逆转排名，不能自行换成疗效分数 |
| `score_distribution`：评分分布图 | 全药物或全条件的直方图/密度图，标明统计对象，可标出展示候选的位置 | 有足够有效分数时生成；不用截断坐标夸大微小差异 |
| `drug_response_heatmap`：药物响应热图 | 行为候选药物/药物浓度，列为预先选定的高响应或疾病相关基因，颜色为预测响应 | 有逐药基因响应时生成；记录基因选择规则、共同尺度和缺测。仅输出排名的后端跳过 |
| `signature_reversal`：疾病特征逆转图 | 将疾病上/下调基因集合映射到药物响应排序，画 GSEA 曲线或两组富集评分；可补疾病变化与药物变化散点图 | 有可靠疾病参照且方向可比时生成；明确余弦评分与 GSEA 是不同计算，不把未执行的 GSEA 画成结果 |
| `score_heatmap`：评分矩阵 | 行为药物，列为细胞类型、样本、细胞系或浓度，颜色为同一定义的分数 | 有多个可比背景/条件时生成；不同后端的原始分数不直接混用同一色标，固定 A549 基线不能标成患者样本 |
| `dose_response`：剂量响应曲线 | 横轴浓度，可用对数轴；纵轴预测表达、通路分数或逆转分数；标出实际计算的浓度点 | 至少两个可比浓度且后端确实建模剂量时生成。仅两点时称剂量比较，不拟合复杂曲线；UniPert-G2CP 当前路线跳过。预测转录曲线不标 IC50 或存活率 |
| `response_similarity`：响应相似性检查图 | 抽样或分块展示不同药物响应的相似性热图及分布，与评分分布配套 | 有逐药响应时默认生成；标明用 Pearson 相关还是余弦相似度，零范数/常数向量单列异常，不能混称 |

仅有原生类别/排名时，只画后端真实提供的分数、名次和覆盖；不能凭药物名称补造基因响应、剂量曲线或疾病逆转结果。多个药物跨浓度排序要保留逐条件分数，并写清均值、最佳浓度或其他汇总策略。

### 退化检查（药筛必做）

交付排名前先判断响应是否真的随药物变化。两个指标：

- `score_spread_across_conditions`：分数在条件间的极差
- `median_pairwise_response_correlation`：不同条件响应向量两两相关的中位数

历史示例的分数极差、响应相似性量级只作为同口径排查参照，不作为跨后端、数据集的统一阈值。检查实际代码使用的是 Pearson 相关还是余弦相似度，在记录中保存公式、抽样、阈值和依据。判退化时状态标 `failed`，写清原因；图表仅作排查，标题标“退化输出诊断”，不作为候选推荐结果。

最容易触发退化的情况是**把用户自己的样本当基线喂给在细胞系上训练的模型**：模型输出被一个与药物无关的共同成分主导，药物那一侧被淹没。

## 共用功能分析与验证图

### 功能富集

- 有可解释的全量基因排序时优先考虑 GSEA，记录排序统计量和方向；ORA 的背景为本次实际可检测/可预测且成功映射的基因集合，不默认使用全基因组。
- 保存基因 ID 转换、基因集数据库及版本、覆盖率、检验和校正结果。仅测 landmark 基因时说明有限基因空间；通路覆盖不足则跳过，不把未测基因当零响应。
- 同时有正负方向时分开报告，或使用有方向的 GSEA。网络影响分数、绝对变化和 embedding 距离不自带激活/抑制方向。
- 没有显著条目时报告“未检出达到阈值的富集项”，可展示明确标注的完整统计表，不放宽阈值凑图。绘图失败与统计结果为空分开记录。

### 有匹配实测数据时生成

- `prediction_vs_observation`：每个点是一个基因，横轴实测相对对照的变化，纵轴预测相对对照的变化；给出一致的参照线和评价基因集。可补绝对表达图，但不能仅凭绝对表达相关评价扰动效果。
- `gene_validation`：用箱线/小提琴展示真实扰动的表达分布，叠加预测汇总点或真实可用的预测分布。没有细胞级预测就不画预测小提琴。
- `effect_agreement`：变化方向一致率、Top 基因重叠或响应误差比较，注明基因集选择规则，验证时用同一集合比较基线与模型。
- 数据条件、基因空间、尺度与批次处理需匹配；区分训练内比较、留出测试和外部验证。按供体/实验重复确定统计单位，不能把生成细胞数量当独立实验重复。
- 火山图需要效应量及有依据的 p 值/FDR；置信区间需要真实重复、明确的重采样单位或模型原生不确定性。固定比例误差条、把随机种子重复当生物学重复均不可用。

## 图形交付与可读性检查

- 数值图用可复现绘图代码生成，不用图像生成模型绘制结果点、曲线或数值。保存绘图脚本或调用参数，优先导出清晰 PNG 与 PDF/SVG，并在实际展示尺寸检查。
- 标题写任务、目标和细胞背景；轴标签写变量与单位；预测、模拟、实测及随机化对照用明确图例区分。默认使用正文语言，保留标准基因名和药物名。
- 同类图固定颜色和尺度；正负响应用以零为中心的发散色，缺测用独立颜色。Top 基因数可按可读性调整，完整表始终保留。
- 状态图先显示细胞群/来源背景，再叠加适量箭头或网格流线，避免遮盖点云；原始扰动、随机化对照和向量差分别标识。图内说明坐标和缩放，不把组织来源标签写成细胞类型。
- 逐张查看导出文件，检查文字重叠、截断、字体缺失、色条含义、图例、图与源数据的一致性。展示检查失败只重画相关图，不自动重跑模型。
- 每张图在报告中用一两句话说明“比较什么、变量是什么、直接观察到什么”，并链接完整源表；不自动添加机制、疗效或实验优先级结论。

### 图与数据清单

在 `figures/figure_manifest.csv` 逐项保存：

`figure_id, task, condition, backend, output_type, question, plot_path, source_table, metric, unit, baseline_source, status, reason`

- `status` 使用 `generated`、`skipped` 或 `failed`，仅表示出图状态；与模型运行状态、独立验证状态分开。
- `source_table` 链接 `tables/` 下实际用于绘图的数值；记录汇总、筛选和标准化口径，可引用保存的绘图参数文件。
- 对任务适用的默认图必须有记录；不适用或缺输入时写明原因，例如无疾病参照、无剂量维度、仅 embedding、基因集覆盖不足。
- 已有历史输出不自动改写为新图组已完成。补图时检查实际保存的数据，保留原图，并在记录中注明新增/重绘产物。

## 对接

只有用户选定药物并确认蛋白后运行。保存：

- 药物和蛋白输入
- 结构来源和版本
- 口袋/网格参数
- 构象文件
- 对接分数
- 阳性对照结果
- 运行日志和失败记录

不输出“已确认靶点”。
